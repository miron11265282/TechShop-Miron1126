# miron1126 TechShop

**Почини. Собери. Разгони.** Игра про ремонт компьютеров от **miron1126** (Godot 4.3).

Начни в 1995 году с Pentium 75 в своей комнате — дойди до небоскрёба в 2026-м: чини ПК клиентов, ставь Windows и Linux, лови вирусы, открой компьютерный клуб. Талисман — кошка Буся.

- 🎮 Скачать: [Releases](../../releases/latest) (Windows, Linux, Android, macOS)
- 🌐 Сайт и игра в браузере: https://miron11265282.github.io/TechShop-Miron1126/
- 📄 Дизайн-документ: [DESIGN.md](DESIGN.md)

## Запуск из исходников
Открой `game/project.godot` в Godot 4.3 и нажми F5.

## Сборка
GitHub Actions собирает все версии при пуше тега `v*` (`.github/workflows/build.yml`).
